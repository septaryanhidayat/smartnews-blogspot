# SmartNews - Blogger / Blogspot News Portal Theme

![SmartNews Theme](https://images.unsplash.com/photo-1504711434969-e33886168f5c?auto=format&fit=crop&w=1200&q=80)

**SmartNews Blogger Theme** adalah template portal berita modern berkelas profesional yang diadaptasi 100% dari sistem portal berita SmartNews Laravel. Tema ini siap pakai untuk platform Blogger / Blogspot dengan kecepatan tinggi, desain elegan, mode gelap terintegrasi, optimasi SEO lengkap, dan tata letak persis seperti versi web Laravel.

---

## 🚀 Fitur Unggulan

- ⚡ **Desain & Struktur Persis Versi Laravel**:
  - **Hero Slider Swiper** 3 kolom responsif di desktop dengan badge media (Video/Foto).
  - **Featured Headline Article** (berita utama dengan foto besar, excerpt, dan metadata).
  - **Section Grid "Nasional"** (4 kartu berita dengan badge kategori & media).
  - **Feed "Berita Terkini"** (kartu horizontal berita terkini lengkap dengan tanggal & penulis).
  - **Sidebar Lengkap**: Berita Populer (Rank 1-5), Iklan Sponsor 300x250, Berita Terbaru dengan thumbnail, dan Topik Populer (Tags Cloud).
  - **Footer 4 Kolom**: Profil media, tautan redaksi, kategori berita, dan badge verifikasi Dewan Pers.
- 🌙 **Dark Mode Terintegrasi**: Mode malam dengan satu klik dan tersimpan di `localStorage`.
- 📱 **100% Responsif & Mobile First**: Dilengkapi offcanvas drawer menu dan pencarian ekspansif di perangkat seluler.
- 🔴 **Live Breaking News Marquee**: Ticker berita berjalan dinamis.
- 🔥 **Trending Tags Ticker**: Navigasi cepat untuk topik-topik terhangat.
- 📰 **Single Post Pro**:
  - Breadcrumb navigasi otomatis
  - Estimasi waktu baca (*Reading Time*)
  - Tombol pengatur ukuran teks (Font Resizer: A-, A, A+)
  - Kotak Ringkasan Berita AI (*AI Summary Highlight*)
  - Tombol berbagi ke WhatsApp, Facebook, X (Twitter), Telegram, dan Salin Link
  - Box Profil Penulis / Redaksi & Komentar Blogger
- 🧹 **Tampilan Bersih**: Menghilangkan seluruh widget bawaan Blogger seperti "Laporkan Penyalahgunaan" dan "Diberdayakan oleh Blogger".

## 🛠️ Cara Pasang & Impor Konten

1. **Pasang Tema**: Buka Blogger -> **Tema** -> **Edit HTML** -> Tempel seluruh isi file **`smartnews-theme.xml`** -> Simpan.
2. **Impor 83 Berita Demo**: Buka Blogger -> **Setelan (Settings)** -> **Kelola Blog** -> **Impor Konten** -> Upload file **`smartnews-demo-content.xml`**.
3. Selesai! Semua berita akan langsung muncul di beranda dan kategori.

Baca panduan lengkap di [PANDUAN-INSTALASI.md](PANDUAN-INSTALASI.md).
